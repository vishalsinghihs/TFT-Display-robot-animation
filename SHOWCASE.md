## 🔄 Animation Sequence

The expressions cycle automatically in this order:

```
    START
      ↓
   Happy (3s)
      ↓
    Sad (3s)
      ↓
  Surprised (3s)
      ↓
   Angry (3s)
      ↓
  Neutral (3s)
      ↓
  Winking (3s)
      ↓
   Sleepy (3s)
      ↓
  Confused (3s)
      ↓
  Excited (3s)
      ↓
   Love (3s)
      ↓
   Sick (3s)
      ↓
  Thinking (3s)
      ↓
   REPEAT
```

## 🎯 Expression Use Cases

| Situation | Recommended Expression |
|-----------|----------------------|
| Robot starts up | Happy → Excited |
| Task completed | Happy or Excited |
| Error occurred | Sad or Angry |
| Low battery | Sleepy or Sad |
| Obstacle detected | Surprised or Angry |
| User interaction | Winking or Happy |
| Processing data | Thinking or Neutral |
| Sensor malfunction | Sick |
| Ambiguous input | Confused |
| Favorite action | Love |
| Idle/waiting | Neutral or Sleepy |
| Achievement unlocked | Excited |

## 💡 Tips for Best Display

1. **Lighting:** Ensure good ambient lighting for display visibility
2. **Viewing Angle:** ILI9341 has ~160° viewing angle
3. **Brightness:** Adjust backlight resistor if needed (100-330Ω)
4. **Timing:** Default 3s per expression, adjustable in code
5. **Colors:** Colors may vary slightly between displays

|-------|----------|-------|
